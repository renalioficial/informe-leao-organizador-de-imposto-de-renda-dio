# 🦁 Informe Leão: Organizador de Declaração de Imposto de Renda

> *Interface e lógica de organização tributária desenvolvida no Excel.*

## 📝 Sobre o Projeto

O **Informe Leão** é um projeto de interface e estruturação de dados criado para resolver a desorganização de documentos na hora de declarar o Imposto de Renda. O foco deste desenvolvimento foi criar uma experiência de usuário (UX) fluida dentro do Excel, eliminando a cara de "planilha comum" e transformando-a em um sistema navegável.

*Projeto desenvolvido como parte do desafio prático do **Bootcamp Santander do DIO**.*

## 🚀 Destaques do Desenvolvimento

Abaixo estão os principais recursos técnicos e visuais implementados na solução:

* **Design de Interface (UI):** Criação de um menu lateral fixo e botões de navegação ("Dashboard"), permitindo transitar entre telas de cadastro e lançamentos de forma intuitiva.
* **Sistemas de Validação:** Implementação de travas de segurança. Ex: Se o usuário digitar um código de banco inexistente, o sistema bloqueia e orienta a correção.
* **Lógica de Consolidação:** Estrutura para somar automaticamente rendimentos de múltiplas fontes e categorizar notas fiscais.
